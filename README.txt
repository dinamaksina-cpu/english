English 5000 Vocabulary Trainer v4 — Reading Edition

Static PWA ready for GitHub Pages, Vercel, Netlify or Cloudflare Pages.
Upload the CONTENTS of this folder.

Vocabulary:
- 5,003 learning cards total: 4,974 Oxford-list cards + 29 reader-support words.
- Tap-to-reveal cards, British speech synthesis, EN -> UA / UA -> EN.
- Random / A-Z / mistakes / favourites / words saved from books.

Quiz & test:
- 4-choice quiz: EN -> UA, UA -> EN or mixed.
- Typed test: UA -> EN.
- Listening test: hear English, type the word.
- Wrong answers automatically added to Review.
- Book vocabulary can be used as a separate quiz/test pool.

Reading / Books:
- 4 graded readers at A1-A2 (18 chapters, 144 translated sentences).
- The Town Mouse and the Country Mouse — A1.
- The Little Red Hen — A1.
- The Secret Garden — A2.
- The Blue Carbuncle — A2.
- All texts are original simplified retellings of public-domain stories, not official Oxford/Penguin/Cambridge editions.
- Tap any word to look it up in the local Oxford 5000 dictionary.
- Select a phrase to see an exact saved phrase translation when available, otherwise contextual sentence translation plus word meanings.
- Add a word or phrase vocabulary directly to the learning list.
- Reader remembers the last chapter and completed chapters.
- Chapter speech uses the device's British English text-to-speech when available.

Progress persistence:
- Stored in localStorage under the existing vocabProgress key, so v2/v3 progress remains compatible on the same domain.
- v4 adds bookWords and readingProgress fields without removing older progress.
- Export/import progress JSON backup includes reading progress and saved book vocabulary.
- PWA cache bumped to vocab-v4.
